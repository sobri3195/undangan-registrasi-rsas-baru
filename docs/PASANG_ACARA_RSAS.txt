2. Impor rsas_acara_19_november_2026.sql melalui phpMyAdmin pada database itu.

   nama database/user berprefix cPanel, password dan host hosting sebenarnya.
   INI SATU-SATUNYA FILE SETTING: private/database.php.
   Isi DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASS di file itu saja.
   APP_TIMEZONE sudah Asia/Jakarta (WIB), tidak perlu diganti.
   Tidak perlu mengubah .htaccess, index.php, API, atau file SQL.
   Saat upgrade, pertahankan konfigurasi Anda yang sudah terisi.
